## Reusable design

For every trained edge,

\[
 G_\ell(t)=G_\ell^0+
 \int_0^t\rho(s)B_\ell(s)\otimes_nX_{\ell-1}(s)\,ds.
\]

Hence

\[
\begin{aligned}
 H_\ell(t)
 &=G_\ell^0X_{\ell-1}(t)+
 \int_0^t\rho(s)B_\ell(s)C^x_{\ell-1}(s,t)\,ds,\\
 G_\ell(t)^*B_\ell(t)
 &=G_\ell^{0*}B_\ell(t)+
 \int_0^t\rho(s)X_{\ell-1}(s)C^b_\ell(s,t)\,ds.
\end{aligned}
\]

The proposed proof IR has population fields, scalars, covariance kernels,
finite signed causal response measures (including same-time atoms), frozen
edge uses in both orientations, and centred chaos/traffic words. Its
semantic invariant is:

> Every omitted connected two-replica diagram must have strictly negative
> glued width degree. Every degree-zero diagram must be contracted into an
> already certified scalar/response object or explicitly promoted.

This is a useful hostile check against silently throwing away an order-one
adaptive operator.

The generic Gaussian rewrite has the formal shape

\[

with the transpose analogue and covariance determined by the query
