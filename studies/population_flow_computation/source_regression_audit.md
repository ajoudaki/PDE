# Audit of regularized Gaussian source regression

Second-round theoretical report, 2026-09-12. Allowed scientific inputs were the coordinator's `source_regression_route.md`, established III.F in `docs/special_data_limits.md`, C.4.7.N2–N8 and A.1–A.2 in `docs/global_nonlinear.md`, and the original scoped assignment. No other route report was read. No experiment or implementation was performed.

**Result.** The source-regression identity is exact for a precisely specified noisy comparison program. It is not exact for an unchanged clean program observed through noisy regressors. A fresh-batch version admits conditional finite-sample error bounds with computable constants; a prefix covariance safeguard is needed. This supplies a new error-production bridge, independent of a finite-network simulation or a width-limit theorem. The resulting generic propagation constants do not give useful resources for error 0.02–0.1 through time 40. That practical claim remains open.

## 1. Exact noisy source rule and the necessary distinction

Index all forward calls by `i` and all reverse calls by `j`, with inputs `H_i` in population 1 and `Delta_j` in population 2. In the mathematical comparison program the actual answers are

\[
Y_i=A_0H_i+s\epsilon_i,\qquad
P_j=A_0^*\Delta_j+s\eta_j,
\tag{1.1}
\]

where every call has its own independent standard Gaussian root on its output population. The original `A0` and its actual adjoint are retained. The learned `K` and `K*` actions are added separately. All subsequent instructions use the noisy answers in (1.1). They never expose the clean answer or the added noise separately.

III.F's source rule, with the additional independent Gaussian roots permitted there, gives unnoised centered sources `xi_i,zeta_j`. Write their sums with the numerical roots as

\[
B_i=\xi_i+s\epsilon_i,\qquad T_j=\zeta_j+s\eta_j.
\]

The two orientation groups are independent, as are the Gaussian roots `g` and all source groups. Their covariances are

\[
C_B=\Gamma_H+s^2I,\quad (\Gamma_H)_{ii'}=E_1[H_iH_{i'}],
\qquad
C_T=\Gamma_\Delta+s^2I,\quad
(\Gamma_\Delta)_{jj'}=E_2[\Delta_j\Delta_{j'}].
\tag{1.2}
\]

The covariance entries are uncentered input moments. The source vectors themselves are centered Gaussian. For fixed positive `s`, both matrices are positive definite, including repeated inputs and zero backward inputs.

To verify that combining the sources is legitimate, proceed through the scalar instructions. An initial root expression is independent of `xi,zeta,epsilon,eta`. At an action answer, the new clean Gaussian source and its numerical noise occur only as their sum. Earlier response coefficients are deterministic numbers. Coordinate instructions and linear combinations preserve dependence only on the sums. Induction therefore shows that every input is a scalar expression in `g`, the available `B` or `T`, and frozen deterministic coefficients. Differentiating at fixed added noise gives

\[
\partial_{\xi_i}F(B)=\partial_{B_i}F(B),\qquad
\partial_{\zeta_j}F(T)=\partial_{T_j}F(T).
\tag{1.3}
\]

Thus III.F.9–10 yield the exact noisy action expressions

\[
Y_i=B_i+\sum_{j<i}\Delta_j\alpha_{ij},
\qquad
P_j=T_j+\sum_{i\le j}H_i\beta_{ji},
\tag{1.4}
\]

with available slots interpreted according to chronological call order, and

\[
\alpha_i=C_T^{-1}E_1[T H_i],\qquad
\beta_j=C_B^{-1}E_2[B\Delta_j].
\tag{1.5}
\]

Indeed Gaussian integration by parts gives `E[S F]=C E[grad_S F]`; (1.3) identifies this derivative with the derivative required by the original initialized action. All feedback coefficients, moments, and covariance entries stay frozen in this differentiation. A.2 supplies integrability of these derivatives for every fixed physical tanh graph, despite the lower backward products. The regression computation itself needs no stored derivative fields.

Three details are indispensable:

* The regressor is the complete saved centered source `B` or `T`, including the numerical output noise. It is not the clean source.
* The regressor is not the complete action answer `Y` or `P`, which also contains response terms.
* The input field in the numerator is the field generated by the noisy program. It is not the clean target's field.

### Errors-in-variables counterexample

Let `U~N(0,v)`, `E~N(0,1)` be independent, `B=U+sE`, and leave the downstream field equal to the clean field `F=U`. Then

\[
(v+s^2)^{-1}E[BF]=v/(v+s^2)\ne1=E[\partial_UF].
\]

If instead the comparison program uses `F=B`, the same regression equals one and is exact. This counterexample distinguishes physical output-noise regularization from merely adding a ridge or corrupting the regressor. Using the clean source in the numerator while inverting the noisy covariance gives the same attenuation issue.

### The noisy adjoint contraction correction

The clean operator inside (1.1) is an actual adjoint pair. The noisy answers themselves do not obey unmodified adjunction. For any forward call `i` and reverse call `j` in a common finite program,

\[
E_2[\Delta_jY_i]-E_1[H_iP_j]
=s^2(\beta_{ji}-\alpha_{ij}),
\tag{1.6}
\]

where an unavailable derivative is zero. To prove this, subtract the two expressions in (1.1). The clean contractions cancel by III.F.27. Gaussian integration by parts in the independent output noises gives

\[
sE[\epsilon_i\Delta_j]=s^2E[\partial_{B_i}\Delta_j],
\quad
sE[\eta_j H_i]=s^2E[\partial_{T_j}H_i].
\]

Their difference is (1.6). For one initial input `H`, take `Y=B` and `Delta=Y`. Then `beta=1`, `alpha=0`, and the contraction difference is exactly `s^2`. Any covariance or response derivation imposing exact adjunction on the *noisy answers* loses this term. Formula (1.5) uses centered sources directly and already accounts for it; no additional correction is added to (1.5).

## 2. Complete causal source program

Use the physical atom law `(u_a,y_a,p_a)`, mesh `h_k`, and `gamma_ka=-2h_k p_a(f_ka-y_a)`. Initialize `w_0=g`, `c_0=0`, empty learned-factor history and empty source groups. Retain all named scalar expressions, numerical coefficient values, source covariance factors, and the random-generator state.

At time `k`, all previously chosen coefficients are fixed:

1. In population 1, construct `H_ka=tanh(w_k dot u_a)`. Estimate or evaluate all needed new `H` Gram rows and `E[T H_ka]`. Compute `alpha_ka` by (1.5).
2. Append the current forward source coordinates with covariance (1.2). Form
   \[
   F_{ka,q}=\alpha_{ka,q}+\gamma_qE_1[H_{ka}H_q],\quad q<k,
   \qquad
   Z_{ka}=B_{ka}+\sum_{q<k}F_{ka,q}\Delta_q.
   \]
3. In population 2, form `V_ka=tanh Z_ka`, `Delta_ka=c_k sech^2 Z_ka`, and `f_ka=E[c_k V_ka]`. Estimate or evaluate the new `Delta` Gram rows and `E[B Delta_ka]`. Compute `beta_ka` by (1.5).
4. Append current reverse sources using their `Delta` Gram. Set
   \[
   D_{ka,q}=\beta_{ka,q}+\mathbf1_{q<k}\gamma_qE_2[\Delta_{ka}\Delta_q],
   \qquad Q_{ka}=T_{ka}+\sum_{q\le k}D_{ka,q}H_q.
   \]
5. Apply the exact displayed physical Euler formulas C.4.7.N2 using these `Z,Q,gamma`. Append the learned factors `gamma_ka Delta_ka tensor H_ka`.

All current forward calls precede the current reverse calls. There is no dense neural matrix in this program. The learned action is retained through the saved factor expressions and their Gram contractions. Population coordinates are sampled from their own Gaussian source groups, never paired as two finite-neuron arrays.

For a passive prediction at `u`, append its `H` expression, response row and forward source; form `Z_u` and estimate `E[c tanh Z_u]`. Retain the query in the source graph if later computation is to reuse the same realized program. A checkpoint contains the entire graph, all selected coefficients and covariance prefixes, time and atom data, and RNG state. The current readout and first-layer samples alone are insufficient.

At exact expectations this is the noisy comparison process proved in section 1. At finite sample size there are two genuinely different implementations below.

## 3. Online representatives versus fresh expression batches

### Persistent online populations

Maintain source and field arrays on two populations of `N` representatives. At each step use their current empirical moments to construct coefficients and append sources. If every covariance is the empirical Gram of the *same retained history array* plus `s^2I`, old blocks are unchanged and positive definiteness is automatic.

However the selected covariance and response coefficients depend on the same representatives later reused to estimate new moments. Conditioning on these coefficients does not make the retained coordinate histories independent draws from the Gaussian law with those coefficients frozen. Applying iid concentration after that conditioning would be invalid. New independent innovations at the next extension do not remove the selection dependence in old fields.

An elementary warning is enough: if a scalar coefficient is selected as the sign of a sample average and the same observations are multiplied by that coefficient, the subsequent average is the absolute value of the old average, not a centered fresh estimate. This does not disprove consistency of the online scheme, but it disproves that particular conditional-unbiasedness argument. The online candidate needs a separate adaptive empirical-process or coupling theorem. No such theorem is proved here.

### Fresh batches evaluating available expressions

Before a batch, freeze every coefficient already selected. Generate independent Gaussian prefixes with the stored covariances and independent lower roots. Reevaluate the saved finite expression graph at these new coordinates. This uses only the available initialized program and its previously computed coefficients. It does not reevaluate old expectations or refit old coefficients, and it uses no target trajectory.

Conditional on the preceding numerical batches, these are iid samples of the currently specified scalar expression law. Thus every sampled contraction has a well-defined conditional expectation and a direct conditional sampling-error bound. This is the principal new bridge supplied by this route.

Fresh batches are used separately at dependency boundaries: a batch estimating `alpha` and `H` moments precedes construction of the new forward law; a later batch estimates the resulting upper moments. Moments not depending on one another may share a batch. Moments whose field expression uses a just-estimated coefficient require a new batch for the elementary conditional argument.

### Fresh prefix rows need a covariance safeguard

Keeping an old empirical covariance prefix and appending rows estimated on fresh samples is not automatically positive semidefinite, despite adding `s^2` to each diagonal. For a repeated bounded input `h`, an old sample can have `h^2` near zero while a new sample has `h^2` near one. The proposed two-source covariance is then near

\[
\begin{pmatrix}s^2&1\\1&1+s^2\end{pmatrix},
\]

whose determinant is negative for small `s`. With `h=tanh G`, the corresponding open events have positive probability, so this obstruction is available even with the present activation and Gaussian root.

Here is an always-defined, prefix-preserving safeguard. Fix `lambda=s^2/2`. Keep each accepted source covariance `C>=lambda I`. After estimating a new row and diagonal, accept the extension only if the extended covariance is at least `lambda I`. Otherwise keep the proposed diagonal, set its new cross row to zero, and flag a failed covariance gate. The diagonal is an empirical nonnegative square plus `s^2`, so the fallback is valid. A factorization of `C-lambda I` permits the gate and extension in quadratic history work. A block of new calls can be appended one coordinate at a time.

Why the fallback can be excluded on a certified good event: let `Q` bound the total source count in either orientation. Require every estimated input-Gram entry to have conditional error at most

\[
\tau_{\rm cov}\le s^2/(4Q).
\tag{3.1}
\]

Old expressions and their source marginals never change when future sources are appended. Therefore the true expectations corresponding to previously saved Gram entries remain the same under every later frozen-prefix law. The assembled empirical covariance is within operator norm `Q tau_cov <= s^2/4` of the genuine full input Gram plus `s^2I`. Its minimum eigenvalue is at least `3s^2/4`, so it passes the gate. This argument requires expression immutability and prefix consistency; replacing earlier covariance blocks by a new full empirical Gram would invalidate that premise.

## 4. A finite, conditional generated-error bound

This section concerns the actual fresh-batch algorithm, including its randomly selected earlier coefficients. It does not appeal to a width limit.

Let `B_k=sum_{q<k}|gamma_q|`, using all atom slots. The saved readout expression obeys the deterministic pointwise bound `|c_k|<=B_k`. Hence

\[
|H_q|\le1,\quad |V_q|\le1,\quad |\Delta_q|\le B_{t(q)},
\quad |c_kV_{ka}|\le B_k.
\tag{4.1}
\]

These bounds are valid with the already selected numerical coefficients; they do not require independence or a gradient-flow energy law. A forward source has variance at most `1+s^2`. A reverse source diagonal is at most `B_k^2+s^2`, because its diagonal was formed from a bounded-square average. The covariance fallback above leaves that diagonal unchanged.

For a fresh batch estimating a scalar moment `E[F]`, the following conditional variance bounds are immediate:

\[
\begin{array}{c|c}
F&\operatorname{Var}(F\mid\text{past})\text{ upper bound}\\\hline
H_iH_j&1\\
\Delta_i\Delta_j&B_i^2B_j^2\\
c_kV_{ka}&B_k^2\\
S_iH_j&C_{ii}\\
S_i\Delta_j&C_{ii}B_j^2
\end{array}
\tag{4.2}
\]

For the last two entries use the pointwise bound on the field and `E[S_i^2]=C_ii`; independence of source and field is neither asserted nor needed. If the variance upper bound is `V`, a batch of size

\[
N\ge V/(\delta\tau^2)
\tag{4.3}
\]

has conditional probability at most `delta` of an absolute mean error exceeding `tau`, by expanding the variance of an iid average and applying Markov's inequality to its squared error. Sample size is selected from quantities known before the batch. Multiple moments in one batch need no mutual independence: allocate failure probabilities to individual moments and take a union bound. Across sequential batches, conditional bounds and the tower property give total failure probability at most the sum of the allocations.

This proves explicit *generated local errors* for the interacting coefficient-selection procedure. It is stronger than merely claiming that a fixed program can be sampled or that an empirical law converges.

### Regression stability and a justified numerical cap

For a fixed frozen-prefix Gaussian law, put `b=C^{-1}E[SF]`. Orthogonal projection onto the linear span of the whitened source coordinates gives

\[
b^TCb\le E[F^2].
\tag{4.4}
\]

To verify it directly, let `a=C^{-1/2}E[SF]` and `Z=C^{-1/2}S`. Then `E[ZZ^T]=I`; expanding `E[(F-a^TZ)^2]>=0` gives `||a||^2<=E[F^2]`.

Thus when `|F|<=B`, the exact response belongs to the ellipsoid `b^TCb<=B^2`. Project the empirical regression row onto that ellipsoid in the `C` inner product. This is a computable radial projection. It cannot increase its `C`-norm error from the frozen-law exact response. If the numerator vector error is `e`, then

\[
\|\widehat b-b\|_C\le\|C^{-1/2}e\|
\le \sqrt2\|e\|/s,
\qquad
\|\widehat b\|\le\sqrt2 B/s.
\tag{4.5}
\]

The input contraction uses its true frozen-law Gram `Gamma`, not `C`. On the good covariance event (3.1), `Gamma <= C` follows from `C=Gamma+s^2I+E` and `||E||<=s^2/4`. Hence (4.5) also bounds the `Gamma`-norm of the regression sampling error. In particular, for `q` numerator entries each accurate to `tau`, the contracted local error is at most `sqrt(2q) tau/s`.

There is a separate covariance-production error: the frozen-prefix covariance differs from the corresponding true input Gram plus `s^2I`. This is bounded by the sampled Gram errors; it is not part of the numerator error in (4.5). It changes the future Gaussian law and must be propagated.

## 5. A computable global finite-graph bound, and its limitation

The local bounds do not on their own imply a final prediction guarantee. One possible rigorous completion for each fixed graph is described here to make the remaining cost issue explicit.

Consider all numerical parameters selected chronologically: Gram entries, source covariance entries, response rows, readouts and physical Euler coefficients. The exact regularized program selects them by conditional expectations under its own preceding deterministic expressions. The fresh algorithm selects them with the moment errors from section 4. All covariance inversions are bounded by `2/s^2`, and the response projection supplies the explicit coefficient bound (4.5).

A deterministic global readout envelope is available without assuming dissipation. From `|fhat_k|<=B_k` and the physical Euler coefficients,

\[
B_{k+1}\le B_k+2h_k(B_k+Y),\qquad B_0=0,
\]

so

\[
B_k\le Y\left(\prod_{\ell<k}(1+2h_\ell)-1\right)
\le Y(e^{2t_k}-1).
\tag{5.1}
\]

This also bounds the exact noisy comparison program. It is a crude finite envelope, not evidence that actual fields grow that quickly.

There is an explicit way to compute finite Lipschitz constants for the required expectation maps without evaluating a high-dimensional integral:

1. Couple the two finite source prefixes by their positive square roots applied to the same finite standard Gaussian vector. If `C,C' >= lambda I`, then
   \[
   \|C^{1/2}-C'^{1/2}\|_F
   \le\frac{\|C-C'\|_F}{2\sqrt\lambda}.
   \tag{5.2}
   \]
   Indeed `D=C^{1/2}-C'^{1/2}` solves `C^{1/2}D+DC'^{1/2}=C-C'`. Diagonalize the left and right positive matrices separately; every matrix entry is divided by the sum of two eigenvalues, at least `2sqrt(lambda)`.
2. Propagate pointwise value and perturbation envelopes through the available expression DAG. Use `|tanh x-tanh y|<=|x-y|`, `|sech^2x-sech^2y|<=2|x-y|`, triangle inequalities for linear combinations, and the product difference identity. `Q` is a source plus a bounded-feature linear combination; therefore its value envelope is at most linear in the absolute standard Gaussian coordinates. Lower gate sensitivity times `Q` increases the degree of a perturbation envelope, but at a finite graph it remains a polynomial.
3. Bound those polynomials by a univariate polynomial in `R=1+sum_i|G_i|`. All Gaussian moments needed for the bound are explicit: for integer `p>=1`,
   \[
   E[R^p]\le(d+1)^{p-1}(1+dE|G|^p),\quad
   E|G|^p=2^{p/2}\Gamma((p+1)/2)/\sqrt\pi.
   \]
   Cauchy–Schwarz converts these into expectation and `L^2` perturbation bounds. This computes conservative constants by finite scalar arithmetic, without tensor quadrature or source-derivative estimation.
4. For inverse regressions use
   \[
   C^{-1}-C'^{-1}=C^{-1}(C'-C)C'^{-1}.
   \]
   The spectral floor supplies the required denominator bounds. Compare the empirical projected response first to the exact response under its own frozen law using (4.5); compare the two exact responses by this inverse identity and the preceding expectation bounds. This avoids any need to prove that projections in two different covariance metrics are jointly nonexpansive.

Consequently one can recursively compute constants `L_j,A_j` such that, on the simultaneous sampling-good event, a norm of all selected parameter errors satisfies

\[
e_j\le(1+L_j)e_{j-1}+A_j\tau_j,
\qquad
e_M\le\sum_{j=1}^M A_j\tau_j
\prod_{\ell=j+1}^M(1+L_\ell).
\tag{5.3}
\]

Here vector dimensions and every matrix-entry count are included in `A_j`; `tau_j` is the allocated scalar moment tolerance. A final expression-envelope bound converts `e_M` to a prediction error. Numerical integration is not hidden in these constants. The recursion is an explicitly constructive finite bound, though its envelope arithmetic and resulting sample counts may be enormous.

This is a conditional finite-graph theorem schema with a fully specified way to obtain its constants. A concrete numerical certificate requires actually evaluating the envelope recursion and its allocated sample sizes for the chosen graph. That computation was not authorized in this round and has not been performed. In particular no numerical error claim follows from displaying (5.3).

### Why this does not yet solve the practical target

At `T=40`, the universal envelope (5.1) contains `e^80`. Even before lower-response propagation, inserting that envelope into (4.2) can make the required sample count useless. Repeated factors from source covariance conditioning contribute powers of `1/s`, and lower gate perturbations can produce high Gaussian moments. Thus this proof route supplies finite, computable error control but presently no plausible useful resource bound.

There is also a visible noise-versus-sampling tradeoff even before propagation. With roughly `Q=800` calls in one orientation, preserving the fresh covariance margin by (3.1) requires entry accuracy at most `s^2/3200`. At `s=0.1` this is about `3.1e-6`; a variance-one Chebyshev estimate for even one such entry requires order `1e11` samples before a confidence factor. This is only the conservative bound of this audit, not a lower bound on what a sharper algorithm or matrix concentration estimate could achieve. It nevertheless rules out presenting this particular certificate as practically useful.

An effective new lemma would replace raw entrywise and graph-length bounds by invariant contraction norms and accumulated-forcing bounds, including adaptively selected coefficient errors. A smaller observed readout norm or favorable empirical covariance alone is not a proof of that lemma.

## 6. Complete costs and outstanding approximation axes

Let `Q` be the total number of action calls, including all physical stages and passive queries. Let a typical fresh batch have `N` samples. Evaluating the entire saved source and field prefix for one sample costs `O(Q^2)` in the uncompressed dense-history representation: Gaussian prefix generation and historical response sums both have that cost.

| Resource | Fresh-batch implementation |
|---|---:|
| Saved expression DAG, response coefficients, learned coefficients, covariance factors | `O(Q^2)` reals/instructions |
| Transient batch source and field arrays | `O(NQ)` reals; chunkable |
| Moment statistics retained between batches | `O(Q^2)` reals |
| Gaussian random coordinates over all batches | `O(NQ^2)` |
| All batch graph reevaluations and contractions | `O(NQ^3)` arithmetic |
| Incremental covariance gates, solves and factorizations | `O(Q^3)` arithmetic |

When batch sizes vary, replace `NQ^3` by the sum of each batch size times the squared prefix length. A covariance inverse should be updated or solved using stored factors; recomputing it at every call would add unnecessary quartic work. The covariance-floor test likewise admits an incremental shifted factorization. All sampling calls to the data law and all additional query/stage costs must be counted. This route uses no neural matrix and no hidden high-dimensional quadrature.

The natural persistent online scheme has lower `O(NQ^2+Q^3)` history arithmetic and `O(NQ+Q^2)` storage, but lacks the fresh-batch conditional error argument. That tradeoff cannot be removed by calling the online samples iid.

A complete comparison to the requested population still needs separate bounds for:

* finite data-law approximation, if the law is not supplied as a finite atom list;
* physical time discretization;
* regularization error from (1.1), including its dependence on the number of calls and physical weights;
* the fresh algorithm's generated covariance and response errors;
* propagation into the requested predictions;
* numerical precision and any covariance-gate failure.

The exact noisy comparison process can be coupled to the clean process through the same actual `A0,A0*` plus explicit independent output roots. That provides a legitimate starting point for a one-reference raw comparison. The empirical algorithm is not itself an exact shared-action process because its source covariances have sampling defects. It must first be compared to the exact noisy scalar source program as above. Skipping that bridge and applying a raw-action estimate directly to empirical coefficients would be unjustified.

## 7. Audit status and next decision

| Statement | Status |
|---|---|
| Full noisy-source regression equals the required source response | Exact, with the sum-only expression condition in section 1 |
| Noisy action outputs satisfy unmodified adjunction | False; correction (1.6) is necessary |
| Regressing clean fields on noisy sources is the same regularization | False; explicit attenuation counterexample |
| Full empirical Gram plus diagonal noise is PSD for retained common samples | Exact |
| Fresh empirical rows appended to a frozen prefix are automatically PSD | False; repeated-input counterexample |
| Prefix gate plus controlled entry errors yields a positive covariance law | Proved finite statement |
| Fresh expression batches have conditional finite-sample source-error bounds | Proved in (4.2)–(4.5) |
| Persistent online samples obey the same conditional iid bounds | Unsupported; selection dependence remains |
| Finite positive-noise source graph admits computable global perturbation bounds | Constructive finite-graph bound mechanism in section 5; constants not instantiated |
| Useful certified error through 40 | Open; current conservative bounds are unusable |

The smallest substantial next obligation is an invariant sampling-and-propagation estimate that avoids entrywise `Q/s^2` accuracy demands and repeated raw-graph Lipschitz losses. Alternatively, a carefully budgeted implementation could test whether the cheaper online scheme has small errors, but that would be empirical evidence and would not supply the missing certificate. No implementation or experiment is authorized by this report itself.
