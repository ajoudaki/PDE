# Quadratic L2 GPU runner-status adjudication

**Written after execution completed but before any scientific trajectory
values were inspected.**

## Observed execution structure

- the parent reported 30 observed bundles out of 30 expected;
- both device workers delivered their `worker_done` sentinel;
- the raw JSONL has exactly one metadata record and 30 bundle records;
- all 30 `(width,key)` pairs are unique and present;
- each width has six bundles;
- each device contributed 15 bundles;
- every bundle contains both registered step sizes;
- there is no error, worker-error, or timeout record.

## Cause of the nonzero launcher status

After the parent receives both `worker_done` sentinels, its collection loop
ends. The cleanup block then immediately calls `terminate()` on any worker
whose operating-system process is still alive, before first allowing its
multiprocessing queue feeder thread to exit normally. Device 0 was in that
short post-sentinel state and consequently received SIGTERM, producing
exit code `-15`. Device 1 had already exited and returned zero.

This termination was generated by the parent only after it had received all
30 bundles and both done sentinels. It therefore cannot truncate a registered
bundle or alter a trajectory already serialized in the raw file. The final
`complete: false` console status is a launcher-lifecycle false negative, not a
scientific or numerical failure.

## Adjudication

The immutable raw JSONL is structurally complete and admissible for the
preregistered numerical gates. It will not be rerun or edited. The nonzero
wrapper exit is retained and disclosed. Scientific admissibility remains
conditional on the independently frozen analyzer finding no missing run,
exceptional record, nonfinite trajectory, memory violation, or step-size
failure.
