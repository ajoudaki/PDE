# Audit index

The independent reports and diagnostic implementations are collected here:

- `pde_derivation.md`: independent derivation and compiler audit;
- `numerical_strategies.md`: separate implementation, depth-noise tests,
  and alternative solver study;
- `final_adversarial_pde_audit.md`: canonical post-simulation hostile
  no-cheat, algebra, restart, quadrature, and claim audit;
- `adversarial_audit.md`: historical gate specification that rejected the
  earlier finite-matrix surrogate;
- `statistical_audit/`: independent curvewise uncertainty analysis.

The main bundle's `results/processed/summary.json` contains the metrics used
in `REPORT.md`.
