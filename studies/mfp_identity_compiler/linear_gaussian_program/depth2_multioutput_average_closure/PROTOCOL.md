# Protocol: multi-output fixed-aggregate feature ascent

Status: frozen before the derivation, 20 August 2026.

## Canonical object

Use \(m\) output heads

\[
f_{a,n}=n^{-3/2}A_a^T W u,\qquad 1\le a\le m,
\]

with independent standard-Gaussian initialization, equal hidden width \(n\),
identity activation, and all displayed blocks trainable.  Fix a deterministic
nonzero coefficient vector \(c\in\mathbb R^m\) and define

\[
g_{c,n}=\sum_{a=1}^m c_a f_{a,n}.
\]

Feature ascent is generated by \(n\nabla g_{c,n}\).  The arithmetic average
is the specialization \(c_a=1/m\).  Physical MSE, when invoked, means the
scalar loss \((y_\star-g_{c,n})^2\).

## Limit and observables

- Take \(n\to\infty\) first with fixed \(m,c,y_\star,\eta\).
- Require uniform convergence in probability on compact physical-time
  intervals.
- Primary observables are \(g_c\) and its scalar MSE loss.
- Individual outputs may be reported, but are not allowed as hidden state
  required to evolve the aggregate.

## Admissible closure

The closure must retain the previous one-dimensional spectral source and a
fixed number of fields independent of \(n\) and \(m\).  Dependence on the
single scalar \(\gamma=\lVert c\rVert_2^2\) is allowed.  It must be
autonomous, restartable, and contain no stored output trajectory.

## Distinctions that may not be blurred

1. Fixed aggregate ascent is not generic vector-MSE training: under vector
   MSE the residual-weighted output direction is generally time dependent.
2. The arithmetic mean \(m^{-1}\sum_a f_a\) and the unit-variance aggregate
   \(m^{-1/2}\sum_a f_a\) have different time/output normalization.
3. Aggregate convergence does not by itself give uniform convergence of all
   coordinates when \(m\) also grows with \(n\).

## Claim ladder and falsifiers

- C1: the finite-width dynamics depend only on one active head combination.
- C2: after deterministic scaling, those dynamics equal the scalar-output
  characteristic exactly.
- C3: the same single-source IDE gives the physical aggregate-MSE limit.
- C4: for fixed \(m\), individual outputs have a deterministic rank-one
  mean-field limit.

A nonzero feedback from an output-head direction orthogonal to \(c\) would
falsify C1.  A residual factor not expressible using only
\(\gamma=\lVert c\rVert^2\) would falsify C2/C3.  Generic vector MSE is outside
this contract unless a separate invariant-orbit theorem is proved.
