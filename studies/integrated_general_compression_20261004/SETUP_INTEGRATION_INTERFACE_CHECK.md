## 1. Legitimate fixed-parameter epsilon specialization

Fix the admissible data, sample count \(m\), input dimension \(d\), hidden
depth \(L\), gap \(\gamma\), positive label RMS \(Y\), activations and
confidence. Let \(n(\varepsilon)\) be the established sufficient dense
inverse width, including the inherited eventual width gates. Then

\[
n(\varepsilon)=\varepsilon^{-2+o(1)},\qquad
\log(en(\varepsilon))=(2+o(1))\log(1/\varepsilon).
\]

Choose the checked original source prescription

\[
T=32(m/\gamma)\log(en),\qquad \eta=1/n.
\]

The error certificate is at most
\(n^{-1+o(1)}=\varepsilon^{2+o(1)}=o(\varepsilon)\).
The last assertion follows by dividing by \(\varepsilon\): the resulting
positive exponent tends to one. Thus this sufficient construction meets
the target eventually while preserving
\(q=O(\log(1/\varepsilon)^{3d/2+1})\) and retained storage
\(O(\log(1/\varepsilon)^{3d+2})\).

The exact source-rank prescription is the checked recipe's
\(q=\min(n,9R)\), or
\(\min(n,\max\{9R,18(2m+d+9)\})\) when retaining the headline domain.
Here \(R\) is the explicitly counted original source generator bound at
the displayed \(T,\eta\). Actual selected support can be smaller than the
budget. At fixed parameters and sufficiently large width, \(9R<n\).

| Setup execution | Sufficient work at this \(n(\varepsilon),T,\eta\) | Peak real words |
|---|---|---|
| Materialized reference, restarted Taylor | \(O(n(\varepsilon)^2\log(en(\varepsilon))^{3d/2+1})=\varepsilon^{-4+o(1)}\) | \(O(n(\varepsilon)^2)=\varepsilon^{-4+o(1)}\) |
| Fresh implicit Gaussian reference | \(O(n(\varepsilon)\log(en(\varepsilon))^{9d/2+3})=\varepsilon^{-2+o(1)}\) | \(O(n(\varepsilon)\log(en(\varepsilon))^{3d/2+1})=\varepsilon^{-2+o(1)}\) |

The equality notation in these table entries describes the sufficient envelope's
asymptotic order, not a matching lower bound on actual work or memory. All
entries use bounded-cost original scalar activation, elementary-function and
Gaussian primitives; exact-real words are not bits.

This is a sufficient stronger-accuracy choice, not a statement that the
least integer inverse of the supplied-budget certificate has these setup
costs. Generic inverse rows can use the complete finite envelopes with their
own \(T,\eta\), explicit order recipe and certified rank fit. They cannot
silently substitute the original-specialization exponents. A clean integration
should either separate the stronger-accuracy row or explicitly state that its
common-epsilon corollary uses this sufficient original prescription.

At the established dense inverse width, the inherited constant confidence-to-
width onset is eventually met but is still not effective. Changing a source
tolerance does not supply a computable width theorem.

supplied entrywise realization or prescribed coordinatewise pseudorandom seed.
Its complete finite setup transcript and final arrays equal the materialized

initial-jet execution's finite coefficient arrays.

optimizer and retained storage are unchanged. No new stochastic event, source
event acceptance test or extra failure budget is introduced. The full original
label interval must use its original activation moment/derivative coefficients;
silently replacing those by loose beta envelopes can narrow it.

The algorithm generates its own anchors using known data and the dense field;
it has no observed-trained-trajectory oracle. Nevertheless it computes across

starts at original time zero, with original activations and exact initialized
source additions; it does not start at the last numerical anchor. No Gaussian

certificates. Analyticity does not give constant-cost scalar evaluation or
exact Gaussian moments. Operation counts use exact reals, exact ranks and
ideal Gaussian samples; finite precision, conditioning, bit complexity,
