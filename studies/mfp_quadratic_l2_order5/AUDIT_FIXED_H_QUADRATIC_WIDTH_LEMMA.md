# Hostile audit of `FIXED_H_QUADRATIC_WIDTH_LEMMA.md`

## Verdict

**Pass.**  Taking the polynomially-smooth finite
NETSOR\({}^\top+\)Moment theorem recorded and audited in
`generic_first_stieltjes/PROBABILISTIC_BRIDGE_AUDIT.md` as an available
result, the alternative lemma closes the fixed-\((N,h)\) quadratic width
bridge.  It avoids every unresolved step in the manual stopping proof:

The conclusion is pointwise in \((N,h)\), exactly as required by the limit

is used.

## 1. Exact compilation of the trained connector

Let

\[
 A=\frac{W^0}{\sqrt n},
 \qquad A_{ij}\sim N(0,1/n).
\]

The simultaneous update is

\[
 W^{s+1}=W^s+\frac h{\sqrt n}C^s(H^s)^T.
\]

Induction gives the exact, finite-width identity

\[
 W^s=W^0+\frac h{\sqrt n}\sum_{r<s}C^r(H^r)^T.
\]

There is no approximation and no replacement of the trained connector by a
fresh matrix.  Multiplying this identity in its two orientations gives

\[
\begin{aligned}
z^s&=AH^s+h\sum_{r<s}
 \left(\frac1n(H^r)^TH^s\right)C^r,\\
b^s&=A^TC^s+h\sum_{r<s}
 \left(\frac1n(C^r)^TC^s\right)H^r.
\end{aligned}                                                    \tag{A.1}
\]

The factors of \(n\) in (A.1) are exact:
the rank-one update contributes \(h/n\) after the additional output
normalization \(1/\sqrt n\).  No hidden width factor remains.

## 2. Chronological language audit

For each \(s=0,\ldots,N-1\), the program can be ordered as follows:

1. `Nonlin+`: \(H^s=\psi(u^s)\);
2. `MatMul`: \(AH^s\);
3. `Moment`: all \(Q_{rs}^{(n)}=n^{-1}(H^r)^TH^s\), \(r<s\);
4. `Nonlin+`: form \(z^s\) using (A.1);
5. `Nonlin+`: \(C^s=a^s\psi'(z^s)\);
6. `MatMul`: \(A^TC^s\), using the transpose of the same initialized
   matrix;
7. `Moment`: all \(K_{rs}^{(n)}=n^{-1}(C^r)^TC^s\), \(r<s\);
8. `Nonlin+`: form \(b^s\), then
   \(a^{s+1}=a^s+h\psi(z^s)\) and
   \(u^{s+1}=u^s+hb^s\psi'(u^s)\).

At the terminal time, append \(H^N=\psi(u^N)\), the final action \(AH^N\),
the historical \(Q_{rN}^{(n)}\), the resulting \(z^N\), and the scalar

\[
 f_n^N=\frac1n\sum_i a_i^N\psi(z_i^N).
\]

Thus the complete matrix-action list is exactly

\[
 AH^0,A^TC^0,\ldots,AH^{N-1},A^TC^{N-1},AH^N.
\]

It has \(2N+1\) entries.  Although there are \(O(N^2)\) moment scalars,
there are only finitely many when \(N\) is fixed, which is all the theorem
requires.  Every operation is literally `MatMul`, `Nonlin+`, or `Moment`.

This ordering also verifies simultaneity: the rank-one sums at time \(s\)
contain exactly \(r<s\), never the current update.

## 3. Hypothesis map

The theorem hypotheses map as follows.

| Required object | Quadratic training program |
|---|---|
| finitely many iid Gaussian matrices with variance \(1/n\) | the single matrix \(A=W^0/\sqrt n\) |
| arbitrary finite reuse in either orientation | the \(2N+1\) alternating actions above |
| iid Gaussian vector sources, independent of matrices | \(a^0,u^0\), independent of \(A\) |
| finitely many scalar moments and their reuse | all \(Q_{rs}^{(n)},K_{rs}^{(n)}\) and the final output |
| polynomially smooth coordinate maps | \(\psi(x)=px+qx^2\), \(\psi'(x)=p+2qx\), sums, products, and compositions |
| fixed program length | \(N<\infty\) is fixed before \(n\to\infty\) |

A polynomial is \(C^\infty\), and all of its derivatives have polynomial
growth (indeed sufficiently high derivatives vanish).  Finite sums,
products, and compositions preserve polynomial smoothness.  The deterministic
scalars \(p,q,h\) have all moments.  Gaussian initialization supplies every
source moment.  Hence every hypothesis of the available all-orders theorem
is met.

No rank-stability assumption is needed by that theorem.  Singular source
covariances and exact linear dependencies are therefore harmless; this
directly removes the spectral gap defect in the manual bridge.

## 4. Limit and annealed output

The invoked theorem gives, for every terminal `Moment` scalar in this fixed
program,

\[
 f_n^N\longrightarrow f_{\mathrm{GP}}^N
 \quad\text{almost surely and in }L^r
 \quad(1\le r<\infty).
\]

The recurrent Gaussian semantics includes the response terms generated by
every repeated \(A/A^T\) action.  Applied to the exact chronological program
in Section 2, it is precisely the inverse-free chronological OMFP Gaussian
program for the same action list.  Therefore

\[
 f_{\mathrm{GP}}^N=F_N(h).
\]

Taking \(r=1\) gives

\[
 \lim_{n\to\infty}\mathbb Ef_n^N=F_N(h).
\]

Uniform integrability is part of the \(L^r\) conclusion and does not need a
separate max-coordinate estimate.

## 5. Limit-order audit

In the no-go application, for each integer \(t\) one first fixes

\[
 N\in\{t,2t\},qquad h\in\{\rho/t,2\rho/t\}.
\]

These are ordinary finite constants while \(n\to\infty\).  The lemma is
applied separately to the fine and coarse fixed programs.  Only after both
width limits have been taken is \(t\to\infty\).  No theorem constant is
required to be uniform in \(t\), and no diagonal limit \(t=t(n)\) is taken.

Almost-sure convergence events may depend on the fixed program.  The no-go
uses deterministic limiting expectations, so a common probability-one event
over all horizons is unnecessary (and a countable intersection would in any
case still have probability one).

## 6. Minor qualifications

- The notation \(q=1\) for the scalar-input setup conflicts typographically
  with \(q\) as the quadratic activation coefficient, but creates no
  mathematical ambiguity once the activation is displayed.
- The lemma should render ordinary mathematics with \(\(N\)\), \(\(h\)\),
  etc.; the current plain parentheses are only a formatting defect.
- The conclusion concerns empirical scalars and Gaussian-program laws of
  generated vector lines.  It should not be read as coordinatewise
  convergence of an entire growing-dimensional vector in a fixed Euclidean
  space.  This distinction does not affect the output theorem.

Subject to those wording fixes, the alternative width lemma is complete and
it closes the only conditional bridge identified in
`AUDIT_NO_GO_UNIVERSAL.md`.
