# Independent review protocol

Each reviewer is a fresh agent with no inherited conversation. Its only reading input is a neutral immutable copy of the complete manuscript; no previous version, preparation notes, reviews, skills, task history, external sources or other agents may be consulted. Every reviewer must read the entire manuscript in nontruncated chunks and record coverage and the input SHA256. All must check correctness and completeness, including explicit hypotheses, dependency closure, constants, limit order, and specialized theorem invocations. Assigned emphases diversify scrutiny but do not limit reading scope.

Every substantive mathematical objection must be recorded, whether or not a repair appears easy. A PASS requires no remaining mathematical correctness or completeness objection. Reports must list any required repairs separately and distinguish optional exposition suggestions. If substantive findings require a change, freeze the corrected manuscript and run an entirely fresh isolated round without disclosing prior findings or verdicts. Completion requires every reviewer in the final round to pass without objections. Mathematical agent review is not formal machine verification.
