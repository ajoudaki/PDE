1. **Tanh conditional target.** The older `RESOLUTION_AUDIT.md` and ledger

   one of them from (AG_T). The zero-label result instead uses a vanishing
   residual clock and short-feature-time equicontinuity.
2. **Tanh initialization containment.** The old report invokes a specialized
   all-moment fixed-program theorem. A needs only a few initial laws. Odd
   readout truncation makes the top instruction bounded-derivative; a second
   odd query truncation handles the next gated product. Existing III.F then
   supplies W2 laws and vanishing square tails, and bounded actions remove
   the truncations. The reverse means vanish by centeredness. This avoids an
   unproved empirical all-moment import. The entropy multiplier estimate and
   input-column identities are written explicitly.
3. **Sin+cos growing mesh.** The corrected 885-line source rejects its own
   all-source bound; the one-step h*sigma*Gaussian example already contradicts
   a q-independent prefactor as h goes to zero first. Its fixed-cutoff
   independent-coordinate finite stability is valid, but its source-law
   completion/restart and uncut uniform-tail identification were not written.
   B keeps exact initialized coefficients and the rejection; it does not use
   that historical fixed-cutoff sketch as a completed local theorem. The
   existing fixed-program proof is used only after bounded-derivative
   truncation. Its expected derivative passage uses the explicit
   Gaussian-plus-bounded finite source laws.
4. **Fixed absolute affine reference.** Polynomial given-space continuation
   is complete. Finite total residual clock is a separate claim; neither
   positive raw Gram nor a mixed-label loss margin follows from the allowed
   separated triples. The augmented kernel bound is kept at the actual
   evolving fields. Full operator balances acquire residual-sum terms. A
   homogeneous trainable-bias augmentation would change the optimizer. The
   source's A=B=0 best-constant example is not imported as a witness in a
   fixed canonical A0+HS/B0+HS coset: setting a non-HS initial action to zero

   one-weak-mode argument and moving residual/constraint algebra. The stronger
