# Completion-pass isolated review protocol

Root coordinates the same physical shared checkout and is the only Git writer.
Review agents are launched with `fork_turns="none"`. Each receives only the
named complete candidate material and explicitly named mathematical dependencies,
a requirement to read solve-math-rigorously personally, a full-read adversarial
review instruction, and prohibitions on project history, other studies, source
audits, earlier reviews/verdicts, Git, experiments, delegation and candidate
edits. Names under the incorporation study directory are candidate delivery
locations, not supplied historical context. Inputs remain frozen during each
review. These agents have filesystem tools, so isolation is by fresh context
and explicit allowed-input contract; a broader filesystem sandbox is not claimed.
Their reports attest actual read scope and unchanged hashes.

| Review identity | Supplied mathematical files | Role |
|---|---|---|
| `/root/plateau_fit_review_a` | Original 930-line plateau candidate, 151-line fitting candidate, 98-line notation | First complete review, then administrative verbatim report persistence only |
| `/root/plateau_fit_review_a2` | Corrected 947-line plateau candidate, same fitting candidate and notation | Fresh full independent review; administrative verbatim persistence follows |
| `/root/plateau_fit_review_b2` | Same corrected three-file packet | Fresh full independent review; administrative verbatim persistence follows |

A1's optional wording points prompted an actual revision and two fresh full
reviews, not a repair-only approval. A2/B2 both report no required correction
at the same hashes. Each administrative report-writing follow-up explicitly
prohibited rereading, further review and edits outside its report path. Original
reports are retained verbatim, including optional observations. No historical
source verdict is counted as an independent incorporation review.
