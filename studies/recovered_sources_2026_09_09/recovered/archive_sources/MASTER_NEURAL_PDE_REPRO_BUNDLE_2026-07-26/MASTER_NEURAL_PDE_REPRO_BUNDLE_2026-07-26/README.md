# Neural-PDE master reproduction bundle

**Collection date:** 26 July 2026  
**Scope:** existing artifacts only

This package collects the code, protocols, archived results, reports, and
seven most useful pre-existing figures behind the empirical claims in the
current master report.

No scientific source file was edited. No experiment, test suite, analysis
runner, plotting script, or figure generator was executed while assembling
this package. Assembly was limited to locating existing releases, copying or
extracting existing bytes, inspecting documentation and archive inventories,
checking hashes/archive integrity, and adding this index plus figure links to
a copy of the master report.

## Start here

- [`MASTER_NEURAL_PDE_REPORT_WITH_FIGURES.md`](MASTER_NEURAL_PDE_REPORT_WITH_FIGURES.md)
  is the current master report with seven existing figures embedded at the
  relevant evidence sections.
- `archives/` contains the original reproduction releases unchanged.
- `figures/` contains byte-for-byte copies of the selected figures.
- `SHA256SUMS.txt` binds every archive, figure, and report/index file in this
  outer package except the checksum file itself.

## Reproduction caveats

1. **Canonical release.** The canonical source release intentionally omits
   roughly \(0.6\)–\(0.7\) GB of raw trajectories and bootstrap arrays. Its
   frozen protocol regenerates them. One historical prototype archive used
   for a secondary implementation-agreement table is not shipped, although
   the independent implementation and tests are included.
2. **Generalization release.** The exact generalization release is nested
   inside the activation archive as
   `activation_linearity_smoking_gun/parent/dense_mup_pde_generalization_repro.zip`.
   It intentionally omits about \(1.35\) GB of raw trajectories.
3. **Lean mini-study.** `PDE_LEAN_SALVAGE_RESULTS.zip` contains the report,
   analysis JSON, and seven raw NPZ archives. The reusable stage machinery is
   in the proof-obligation bundle, but the exact ad hoc mini-runner and command
   manifest were not preserved. Those particular mini trajectories are
   evidence-preserved, not turnkey source-reproducible.
4. **Scalar extraction layout.** The scalar ZIP stores
   `one_input_hermite_ladder.py` at its archive root, while the unchanged code
   resolves dependencies from a parent project directory. For reproduction,
   extract its contents into a directory named
   `minimal_nonlinear_hermite/`, with the extracted
   `activation_linearity_smoking_gun/` and
   `pde_proof_obligation_audit/` trees as siblings. Do not edit the runner to
   compensate for the ZIP layout.
5. **Finite-matrix response hierarchy.** The long-horizon \(q/r\) archive is
   fully self-contained, including raw traces. Its projected systems retain
   every dense \(W_\ell\); they test the response-compression mechanism and
   do not constitute runs of the width-independent Liouville PDE.
6. **Historical interpretations.** The canonical release retains its
   historical operator-order tables. The current parity-correct conclusion is
   the one in the master report: the old \(P=5\to15\to35\) adverse ratio used
   an exactly inert even shell and is superseded.

## Deliberate exclusions

- The standalone generalization ZIP is omitted because the exact same archive
  is already nested in the activation release.
- `PDE_HIGH_TO_LOW_TAIL_ROUND_BUNDLE.zip` is omitted because the final
  compactness bundle contains its full report, source, analysis, and results.
- The earlier `dense_euclidean_continuous_depth_npde_bundle.zip` is omitted
  from this current-evidence package because the corrected long-horizon
  response archive supersedes the numerical response-accuracy claims quoted
  in the master report.
- The invalid antithetic parity pilot is excluded; it used the wrong sign map
  and is rejected by the parity-round manifest.
- Loose raw activation trajectories, duplicate extracted release trees,
  Python bytecode, duplicate figures, and redundant detail plots are omitted.
- No figure existed for the scalar sine stress, scalar Hermite ladder,
  degree-seven tail, or final compactness ledger. None was fabricated.
