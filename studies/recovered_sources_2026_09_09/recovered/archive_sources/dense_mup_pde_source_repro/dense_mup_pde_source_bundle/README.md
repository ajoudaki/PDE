# Compact source-first reproducibility bundle

This is the downloadable edition of the genuine dense-\(\mu\)P neural-PDE
experiment. It contains the complete source, frozen protocol, tests,
processed evidence, audit material, and two central figures. It deliberately
does **not** contain the large raw `.npz` trajectories.

The omitted raw arrays account for essentially all of the former 689 MB
archive. They are generated locally by the included protocol.

## Read first

- `FINAL_DENSE_MUP_PDE_CONJECTURE_REPORT.md` — current self-contained
  conjecture and evidence assessment.
- `dense_mup_pde_repro/REPORT.md` — report for the completed direct-PDE
  experiment.
- `dense_mup_pde_repro/theory/operator_galerkin_pde.md` — PDE derivation.
- `dense_mup_pde_repro/README.md` — source and command map.
- `agent_outputs/final_adversarial_pde_audit.md` — final hostile audit.

## What is included

- the explicit operator–Galerkin PDE and characteristic solver;
- a self-contained exact dense-network reference;
- the main and independently written unit-test suites;
- the full canonical regeneration protocol;
- statistical and hostile audit code;
- compact CSV/JSON summaries of the frozen run;
- `pde_vs_dense_curves.png` and `pde_plateau_tail.png`;
- the recorded Python/package environment; and
- separate integrity manifests for immutable source and distributed
  result snapshots.

## What is omitted

- raw PDE and dense-network trajectory archives;
- pooled raw `.npz` arrays;
- bootstrap-distribution `.npz` arrays;
- historical prototype archives and Python bytecode.

The compact snapshots let the reported numbers be inspected immediately.
They are not substitutes for regenerating the raw evidence.

- Matplotlib 3.10.8; and

The exact top-level versions are in

## Verify the compact source and snapshot

From this directory:

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -r dense_mup_pde_repro/requirements-lock.txt
bash verify_source_only.sh
bash verify_snapshot.sh
```

`verify_source_only.sh` checks immutable source integrity, dependencies,
syntax, anti-oracle separation, and both unit-test suites.
`verify_snapshot.sh` additionally checks the absence of bundled NPZs, the
size bound, figures, and compact result summaries.

## Regenerate the canonical evidence

From this directory:

```bash
. .venv/bin/activate
WORKERS=8 bash dense_mup_pde_repro/protocol/reproduce_full.sh
bash verify_reproduced_core.sh
```

For a low-memory machine, use `WORKERS=1`.

The recorded canonical run took about 2.1 hours of sequential job wall time
on a 9-logical-CPU Intel Xeon Platinum 8573C environment. Parallel execution
changes elapsed time. Allow at least 2 GB of free disk space; the regenerated
raw and pooled arrays occupy roughly 0.6–0.7 GB.

The full protocol:

1. runs algebraic PDE and dense-reference tests;
2. integrates the primary PDE and its \(t=8\to32\) autonomous continuation;
3. runs time, depth, cubature, scramble, and Hermite-order refinements;
4. generates all canonical dense-reference ensembles;
5. combines reference blocks;
6. regenerates the paired-\(W\) homogenization diagnostic;
7. rebuilds the main figures and compact tables; and
8. reruns the statistical audits.

The PDE trajectories are generated before dense references are used for
comparison. Dense-reference files never enter the PDE velocity.

## Verification scope

The compact release reproduces the canonical headline protocol and its
processed metrics. It does not attempt to recreate every historical pilot
archive that happened to be present in the former large bundle.

The independent implementation is included and tested as a separate
deterministic algebraic/semigroup check. The exact historical prototype
archive used for one implementation-agreement table is not shipped and is
not regenerated by the canonical protocol; it is not needed for the
headline PDE/dense comparison.

Regenerated `.npz` files are not expected to have identical byte hashes
across machines because ZIP timestamps, elapsed-time metadata, and one
restart path are environment-dependent. `verify_reproduced_core.sh` checks
archive completeness, finiteness, anti-oracle separation, and the declared
scientific metrics within numerical tolerances instead.

## Integrity files

- `SOURCE_MANIFEST.sha256` covers immutable code, configuration, reports,
  and instructions.
- `SNAPSHOT_MANIFEST.sha256` covers the distributed compact result tables
  and figures.

After a full rerun, generated figures and tables may legitimately differ in
bytes even when their scientific metrics agree; rerun
`verify_reproduced_core.sh` rather than expecting the original snapshot
manifest to pass.
