# Infrequent dense writes through response-memory buffering

Protocol frozen before implementation and runs, 2026-10-01. This is a scoped empirical route in the parent study. Inputs: its unchanged baseline implementation, current paper network/ordinary activity-clock equations and exact velocity-defect identity. No other study results are inputs.

## Decision question and competing explanations

Can a small response-memory buffer preserve canonical feature learning while the hidden base matrix is written infrequently? H1: feedback through the reconstructed matrix gives materially better agreement with dense learning than delayed updates with the same dense-write schedule. H0: merely batching the hidden updates is equally effective; the buffer is unnecessary. A separate direct-factor control tests whether arbitrary trained low-rank updates suffice.

Use two hidden tanh layers, width 256, eight fixed circle inputs, unit labels sign(cos(3 theta)), angles theta=2 pi (a+0.13)/8; inputs passed to Flow equal (cos theta,sin theta), corresponding to raw x of norm sqrt(2). Gaussian first weights have variance 1, hidden weights variance 1/n, readout is explicitly zero, no biases/normalization, canonical mobilities (n,1,n), unhalved mean squared loss. Fixed support retains the sample indexing needed by the ordinary closure, while a nonlinear odd target makes this a fitting problem representable by this architecture. This is an algorithm experiment, outside the paper's small-label all-time guarantee.

## Methods and exact construction

Adapt baseline Flow, keeping it byte-for-byte unchanged. Test dense flow; unflushed q=1 and q=3; q=1 buffers consolidated every 8 or 32 physical-time units; q=3 buffer consolidated every 32; q=1 defect-triggered buffer; and direct factor flow of rank 24 with both baseline factor seed and one independent seed. Consolidation adds the low-rank correction to the base hidden matrix, resets tau to 1, sets the zeroth forward prefix to the current feature and all other forward and backward moments to zero. It preserves the entire represented function but changes subsequent dynamics. It is not the paper's uninterrupted all-time regime.

Delayed-update controls freeze the hidden matrix between exactly the same flush times, while training the first layer and readout. At each integration stage they store current residual-weighted backward responses and forward features; at flush they apply the sum of their outer products in one matrix operation. Thus no n by n accumulator is updated each step, and the baseline uses the full uncompressed delayed gradient history. Charge its larger buffer and contraction work. Include both learning-rate multipliers 1 and 0.25 in pilots; select the better fixed pilot multiplier, before confirmation, for each schedule. This control receives no dense trajectory information. Distinct flush schedules receive separately matched delayed controls; the defect schedule is determined only by the buffer run and replayed by its control.

For tau=1+s, endpoint projections are h*=sum_j(2j+1) bar h_j/tau and b*=sum_j(2j+1) bar delta_j/tau. The exact continuous hidden velocity defect is E=2/(nm) sum_a(r_a delta_a-rho b*_a)(h_a-h*_a)^T. Compute its Frobenius norm from m by m Gram matrices when required, without forming E. The scalar sum 2/(nm) sum_a ||r_a delta_a-rho b*_a|| ||h_a-h*_a|| bounds ||E||_F. Trigger consolidation when the physical-time integral of this bound since last flush reaches 0.002 sqrt(n); no global trajectory guarantee is claimed. Also record diagnostic wall-time and operation counts.

## Outcomes and discriminator

Primary metric: RMS whole-circle discrepancy from dense at common physical times (513 uniform query angles), averaged over t=8,16,32,64,128,256. Report endpoint training RMS and sign classification accuracy against the analytic target separately. Dense reference shares initialization. Success requires q=1 or q=3 buffered average discrepancy at most half its matched delayed-control discrepancy, discrepancy <=0.1, final training RMS <=0.1, and at least 10-fold fewer hidden dense writes than dense flow; require this in at least four of five fresh confirmation seeds. Failure means every valid buffer fails the factor-two criterion or absolute thresholds; an indifference region or numerical violation is inconclusive. Direct factors are a stronger scope check: if they match/better the buffer at this resource level, qualify the use case accordingly; no universal superiority claim.
