# Arctangent three-hidden-layer target

Status: all base gates passed; D3 attempted but not promoted.

The linear, generic-shallow, and two-hidden-layer nonlinear gates now pass.
Two isolated structural compiler probes established the exact current-state
candidate, fixed-grid semantics, and nonexplosion, but both stopped at
multi-action continuous-time uniformization. A third isolated reconciliation verified that the nested
two-colour first-Jacobian word is generically order one, while rejecting both
the inference that it necessarily creates a new traffic state and the
inference that a finite second response automatically closes it. See
[the frontier audit](TWO_COLOUR_FRONTIER_AUDIT.md).

The first proposed reopen condition required the augmented state and its
first two variations to be uniformly Cauchy across meshes. A fourth isolated
audit rejected that as essentially the original theorem in stronger
notation; see [the reduction audit](SECOND_ORDER_REDUCTION_HOSTILE_AUDIT.md).
Direct execution of all promoted rules then failed at the first
middle-backward multiplier estimate; see
[the D3 execution report](D3_CALCULUS_EXECUTION.md). Bare \(L^2\) stability
is false, and any one fixed \(L^p\) envelope gives only a non-Osgood Hölder
modulus.

The smallest current target is instead a **local one-step**
correlated-multiplier/gluing estimate with a linear or Osgood modulus and a
width remainder carrying the Euler step-size. Global mesh Cauchy must be
derived from that estimate. A concrete sufficient analytic certificate is a
uniform subexponential/Orlicz tail for the dependent action
\(\Gamma_3^*B_3\) and its tangent returns; the learned part of \(Q_2\) is
already bounded. A clean-slate
[stopped two-sided cavity blueprint](STOPPED_TWO_SIDED_CAVITY_BLUEPRINT.md)
targeted that estimate, but its
[hostile audit](STOPPED_CAVITY_HOSTILE_AUDIT.md) rejected fixed-order
variation, response-trace self-averaging, and fixed-\(p\) stop removal as
insufficient. The corrected program needs an exact all-return one-site
Volterra cavity equation and restartable empirical \(\psi_1\) control.
Failure of finite response closure would force an explicit traffic
promotion. The exact target remains the frozen D3 contract; this directory
may not weaken it.
