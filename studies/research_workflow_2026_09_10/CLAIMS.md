# Claims and disposition

These are operational maintenance claims, not mathematical results. No theorem,
scientific API or empirical research conclusion is promoted by this study.

| ID | Claim and scope | Evidence and disposition |
|---|---|---|
| W1 | Versioned root instructions route ordinary research tasks to the complete lifecycle and confine authored research to one flat study with private generated data. | AGENTS.md and RESEARCH_WORKFLOW.md; two full process reviews clean. Following instructions is required; OS enforcement is not claimed. |
| W2 | The stdlib helper initializes/adopts records without overwriting existing work, freezes selected packets and detects the documented structural/hash failures. | Complete helper/tests, ten deterministic tests and independent attacks; paired code reviews clean. It cannot certify scientific merit, honest reports, semantic closure or actual reviewer independence. |
| W3 | Automatic entry worked for a fresh task in the tested checkout/profile. | AUTO_LOADING.json: actual successful run, startup self-report, complete workflow read in event stream. This does not verify the other credential's private settings or hot reload of an existing task. |
| W4 | Installation preserves the scientific edition and inherited work. | PRESERVATION.json and START.json; 27 accepted scientific files hash-identical, 14 inherited paths preserved, eight by metadata only. Separate full integration review clean; exact live bytes verified. |

Deliberate exclusions: no OS sandbox engine, automatic mathematical decision
procedure, blind Git hook, global profile changes, retroactive study migration,
or new training/reproduction campaign. Prompt-file bytes are not covered by the
helper's scientific-input digest; the coordinator must validate the actual neutral
assignment and completion provenance. Cross-credential file/lock access must be
checked when coordinating those writers. These limits are not concealed failures
of a scientific promotion; no scientific promotion is attempted here.
