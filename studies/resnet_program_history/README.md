# ResNet PDE program

This is a study record, not an established-library entry. Historical claims and
review labels below retain their original scope; consult the
[reconciled research map](../project_wide_audit_2026_09_08/MASTER_RESEARCH_REPORT.md)
for current qualifications and the [maintained library](../../docs/README.md)
for accepted self-contained presentations.

The maintained scientific status, evidence ledger, supersession rules, and
reading order are in
[`CURRENT_RESEARCH_STATE.md`](CURRENT_RESEARCH_STATE.md).

The three substudies are:

- [`dense_response`](dense_response): finite-matrix response mechanism;
- [`operator_pde`](operator_pde): explicit finite-cutoff PDE and direct
  empirical tests; and
- [`pde_convergence`](pde_convergence): parity, hierarchy, compactness, and
  stability audit.

These concern the repository's fully connected Euclidean-\(\mu\)P residual
laboratory, not convolutional or general-purpose ResNets.
