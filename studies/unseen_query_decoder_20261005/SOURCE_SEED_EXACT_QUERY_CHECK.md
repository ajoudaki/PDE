## 2. Finite transcript transfer

Fix the independent scalar-noise string e and one external input/time code.
Pad every possible scalar transcript to the same B-bit format, including
lengths, branch decisions, guards, failure flags, and the final output. For a
candidate transcript c, evaluate every row test at the earlier scalar values
hardwired from c. Its exact dyadic contribution is added to the corresponding
accumulator. This needs all P accumulators simultaneously, but no previous row.
The row counter and exact-sum ranges are included in s.

After the last row, compare every resulting rounded/noisy scalar instruction
with c. If the test accepts, induction over scalar instructions establishes
that c is the actual transcript: equality of the earlier prefix makes its next
row operands identical, and the checked reduction gives the next scalar.
Conversely, the actual transcript passes. This includes innovation contractions:
their coefficients precede the fresh innovation, and their completed affine
answers are deterministic row operations once the contraction is supplied.

Nisan's Lemma 3 gives, for a universal c>0, 2^k blocks of length A, fooling all
machines with at most 2^(cA) states between blocks to error 2^(-cA), provided
k<=cA. Computation within a block is unrestricted. The stated recursive hash
family has linear description size. See [Nisan, Sections 2–4, especially
Lemma 3](https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2013W/Nisan_PRG.pdf).

In this application choose k=ceil(log2 n), enlarge the block to contain the
Dp source bits, and make

    A >= C[Dp+s+B+log(n+2)+log(1/epsilon)].

Then s<=cA, k<=cA, and the error per candidate is at most
epsilon*2^(-B-1). Extra blocks are ignored. Summing absolute errors over at
most 2^B candidate strings proves the total variation bound in (3). Averaging
over the independent e preserves it. The transition table can hardwire c and
e; neither is retained in the implemented model as proof advice. The actual
implementation does not enumerate these tests.

The physical query output must be included in T or be deterministic from T and
e. The candidate's final readout reduction supplies exactly this condition.
With P,B/p,s/p=O(R^2) and D=O(R), the source seed and scalar-noise string have

## 6. State semantics and resource reconstruction

The setup metric may depend on the completed source, as explicitly permitted.
After setup, current state consists of the selected metric, selected finite
packets, acquired scalar history/coefficient vectors, and the independent
scalar-noise marks or their regenerating seed. Selected-packet updates use the
same deterministic finite row instructions. A query regenerates the original
rows and re-evaluates old named fields with *already acquired* scalar arguments.
It appends only passive query reductions. It does not recompute past scalar
training updates, recover future scalar answers, or advance to an unavailable
patch. The source seeds encode random inputs, not fitted predictions.

Scalar-noise storage must be included explicitly in the per-member O(R^2 p)
state, as it is in the inherited metric-acquisition bound. Keeping those marks
avoids repeatedly regenerating an outer block at every individual training
update. Alternatively every such regeneration must be counted; one cannot
charge a single outer generation for arbitrarily many regenerations. There is
an admissible implementation with the displayed memory bound and no row
generation during compact training.

Write E=1+ceil(log2(n+2)), A=O(R^2 p),
b=O(R^2 p E+log(N_ext/delta)), and J=O(log(N_ext/delta)). The retained/peak
training-query memory consists of J member states, the outer seed, one member
block, row scratch and small matrices, and J scalar answers. It is

\[
 C[JR^2p+b\log(J+2)].
\]

Sequential setup adds only one temporary full table and exact metric workspace,
