## 3. Batched algorithm and exact finite failure predicate

Fix one source prefix, one external code, and one passive stage. Hold the
incoming guarded moments and all prepared coefficients fixed. Generate
the same fixed-length packet stream as in the prior-block algorithm.
For each packet evaluate its finite training marks once, whiten them once,
and compute all required vector and scalar integrands. Accumulate each
coordinate in its own running block sum. At block completion, use the
same finite division and rounding as the original coordinate routine and
store that block's entire mean vector. After all \(J\) blocks, compute
each coordinate median and only then update the stage's guarded context.

This is exactly the vector of medians produced by coordinate reruns on
the same stream: each coordinate sees the same packet order, finite row
values, accumulator rule and rounded block means. Interleaving independent
coordinate accumulators does not change their operations. No row result
depends on a partly completed median. Batching changes execution order
and caching, not the estimator or its statistical error.

For the generator proof, fix lower and upper rational thresholds for each
coordinate, with the usual statistical/rounding margin. A one-pass test
stores the vector of current block sums, upper- and lower-threshold block
counts, and common row/block counters. At each block boundary it performs
the exact implemented block-mean rounding before thresholding. At the end
it accepts if some coordinate has at least \((J+1)/2\) blocks beyond
one of its thresholds. This is exactly the union of coordinate-median
failures. Its complement implies the desired Euclidean error bound; no
claim that this predicate exactly tests an arbitrary Euclidean ball is
needed.

The test's between-packet state is \(O(Rp)\) bits. Running sums include
integer range and \(\log s\), while threshold counts use \(\log J\);
these fit the chosen local words. The source, context, coefficient arrays
and proof thresholds are fixed advice for this test, not extra decoder
inputs. Per-packet row scratch is discarded at the boundary, as permitted
by the explicitly inherited block-generator interface. The decoder's
larger stored block-mean array is charged separately.

One packet uses \(O(Dp)\), \(D\le CR\), random bits; unused
coordinates are padded. With \(N=Js\) and
\(E=1+\lceil\log_2(N+2)\rceil\le Cp\), take

\[
 A=C(Dp+S_{m test}+F+E)=O(Rp).
\]

The assigned generator interface then gives \(O(Rp^2)\) seed bits per
stage, \(O(R^2p^3)\) work per packet, and \(O(Rp)\) generator
scratch. This is an application of the supplied between-block-state
theorem, not a newly proved generator or a claim of independent generated
rows. If a shared Gaussian-tail test is retained, its one flag and
counters fit the same state; the finite-prior passive proof can instead
charge its fresh finite-Gaussian expectation bias directly.

Independent stage seeds support the reachable-context union: conditioned
on earlier seeds, each external code reaches one fixed current context,
independent of the current seed. The proof does not assume that context
was reached successfully, and it does not enumerate all possible earlier
numerical outputs. Whole-event transfer and exact replay use the same
final finite decoder as in the corrected passive proof.

\[

\[

The separately frozen tanh proof is valid for precision \(p\ge1\).
For a nonnegative represented input, the integer cutoff \(p+4\)
has tail error \(2e^{-2(p+4)}<2^{-p-3}\). Below it, choose
\(2^k\le4(p+4)\) with \(z=2x/2^k\le1\). The alternating
exponential series uses \(O(p)\) terms; its factorial remainder is
smaller than the required \(2^{-p}/\operatorname{poly}(p)\).
Rounded recurrence and summation add at most
\(CJ^2 2^{-b}\), \(b=p+C\log(p+2)+C\). Clipping is
nonexpansive relative to the exact exponential, and \(k\) clipped
squarings amplify this error by at most \(2^k=O(p)\). Fixed large
guard constants therefore give the stated \(2^{-p-5}\) exponential
accuracy. The final map \((1-u)/(1+u)\) has denominator at least
one and derivative magnitude at most two on \([0,1]\). Oddness
and the real derivative bound \(|\tanh'|\le1\) handle negative
and inexact inputs with the stated input-access allowance.

Schoolbook arithmetic uses \(O(p^3)\) bit work and \(O(p)\)
scratch. Activation costs then add
\(CnR^3p^3\), \(CR^4p^3\), and
\(CQ(n/R+R^2)p^3\), respectively. These are covered by existing
metric, update, and query terms, without assuming \(p\le R\).
The tanh activation contribution therefore needs no larger displayed
powers. This does not certify arbitrary analytic evaluator complexity or
erase the remaining input and certificate charges.
