## 3. L2 arctan: a substantive repaired exact-flow limit

### Exact model and observables

There are two nonlinear hidden layers, equal width \(n\), one unit input sample and one fixed scalar label \(y\). Write

\[
 X=\arctan u,\quad Z=GX,\quad Y=\arctan Z,\quad
 f_n=\langle A,Y\rangle_n,
 \qquad \langle v,w\rangle_n=n^{-1}v^\top w.
\]

The input coordinates and readout initialize independently as \(N(0,1)\); \(G_0=W_0/\sqrt n\) is independent Ginibre with variance \(1/n\). The readout coordinates are **order one**, despite \(f_n(0)\to0\). Vector parameters use the normalized Hilbert metric and \(G\) the ordinary Frobenius metric; equivalently the raw parameters \(u,A,W\) use the \(n^{-1}\)-Euclidean metric. Full MSE is \((y-f)^2\), with physical gradient flow \(\dot\theta=2\eta(y-f)\nabla f\). This is not a tiny-readout initialization, a frozen readout, or a readout-only optimizer. [Setup and theorem](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:5).

With \(r=u+u^3/3\), \(X=\Psi(r)\), \(c=(1+u^2)^{-1}\), \(d=(1+Z^2)^{-1}\), \(B=Ad\), \(Q=G^*B\), signed feature time gives

\[
 A'=Y,\quad r'=Q,\quad (G-G_0)'=B\otimes X,
 \qquad K=\|Y\|_2^2+\|B\|_2^2\|X\|_2^2+\|cQ\|_2^2,
\]

where \(b\otimes x=bx^\top/n\) at finite width. In particular \(f'=K\). All three parameter groups are trained; matrix-gradient normalization and the input contribution agree with direct differentiation. The limiting current state uses a fixed immutable pointed action source, two current fields, a trace-class learned operator and residual. The actual source adjoint is retained. This is an infinite-dimensional autonomous state, not discarded transpose memory or operator-norm convergence of matrices between widths. [Source realization](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:312).

### Decisive proof skeleton checked

1. Bounded activation gives the pathwise envelope \(|A(s)-A_0|\le\pi |s|/2\), normalized state bounds and trace/operator bounds on each bounded feature interval. With readout initialization clipped at \(M\), the vector field has a dimension-independent local Lipschitz constant; Euler error is \(C(M,S)h\). Each fixed mesh is a finite transpose-reusing program, so the imported theorem identifies its joint laws and all fixed moments.
2. For the unclipped source, the Gaussian readout envelope gives the multiplier modulus \(\delta\sqrt{\log(e/\delta)}\). Its reciprocal is nonintegrable at zero, giving Osgood uniqueness. Clipped solutions are Cauchy and yield global feature-time existence and continuous raw kernel. [Well-posedness proof](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:462).
3. The crucial raw-square step is not a weak-law argument. The corrected proof uses
   \[
   q^2\mathbf1_{|q|>R}\le4(q-v)^2+2v^2\mathbf1_{|v|>R/2}.
   \]
   First fix **one auxiliary mesh** fine enough for \(L^2\) approximation, then take the tail height large using that fixed program's moments. This establishes square UI for the exact clipped flow. Only afterwards compare kernels, truncate at a fixed height, and remove the comparison mesh. This avoids the historical invalid product \(hC_{p,h}\). [Repaired kernel bridge](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:687).
4. Cutoff removal uses the asymmetric expansion \(Ad(Z)-A^Md(Z^M)=(A-A^M)d(Z)+A^M[d(Z)-d(Z^M)]\). Amplification of order \(e^{C_SM}\) is beaten by the Gaussian clipping error of order \((1+M)e^{-M^2/4}\). UI transfers to the original raw kernel. [Cutoff proof](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:813).
5. Solve the scalar physical clock \(\dot s=2\eta(y-F(s))\). Monotonicity \(F'=K\ge0\) bounds the limiting clock by \(2\eta|y|T\); finite clocks use their actual residual \(y-f_n(0)\), not exactly \(y\). Uniform feature-time convergence transfers to each compact physical horizon. [Clock and loss](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:879).

## 5. RMS quadratic: finite-width bounds are not kinetic UI

### Model and valid identities

This is a two-hidden-layer, one-sample square network with widthwise RMS normalization **after** each square, fixed \(\varepsilon>0\), independent standard Gaussian raw \(u_0,A_0,W_0\), \(G=W/\sqrt n\), and the same mixed metric/full-MSE physical clock as above. Readout coordinates are order one. Normalization denominators are differentiated; they are not frozen statistics or a different optimizer. [Protocol](/home/amir/Codes/PDE/studies/mean_field_peeling/quadratic_compiler/rms_normalized_operator_closure/PROTOCOL.md:1).

Set

\[
 \alpha^2=\langle u^4\rangle_n+\varepsilon,\quad H=u^2/\alpha,
 \quad Z=GH,\quad\beta^2=\langle Z^4\rangle_n+\varepsilon,
 \quad Y=Z^2/\beta,\quad f=\langle A,Y\rangle_n,
\]
\[
 C=A-fY,\quad R=2ZC/\beta,\quad g=G^*R,\quad T=(I-H\otimes H)g.
\]

The exact feature-ascent system and raw kernel are

\[
 A'=Y,\qquad G'=R\otimes H,\qquad u'=2uT/\alpha,
\]
\[
 K=\|Y\|_n^2+\|H\|_n^2\|R\|_n^2+
       {4\over\alpha}\langle HT^2\rangle_n.
\]

For \(N_\varepsilon(v)=v/\sqrt{\|v\|_n^2+\varepsilon}\), \(DN=\sigma^{-1}(I-N\otimes N)\). The factor in parentheses is not an orthogonal projection at positive epsilon: its radial eigenvalue is \(\varepsilon/\sigma^2\). Bounded normalized RMS does not bound individual coordinates. [Finite theorem](/home/amir/Codes/PDE/studies/mean_field_peeling/quadratic_compiler/rms_normalized_operator_closure/FINITE_WIDTH_THEOREM.md:6).

Positive denominators give a smooth finite ODE; physical loss dissipation supplies

\[
 \int_s^t\|\dot\theta\|_\mu^2\,dr
   =\eta(\mathcal L(s)-\mathcal L(t)),\qquad
 \|\theta(t)-\theta(s)\|_\mu
   \le\sqrt{\eta(t-s)(\mathcal L(s)-\mathcal L(t))}.
\]

This proves finite-time existence and action control, not a raw-kernel limit. Additional one-sided feature-time bounds use \(m=\langle u^2\rangle_n\), \(m'=8\varepsilon^2 f/(\alpha^2\beta^2)\), \(f'\ge0\), and \(f(0)\ge-n^{-1/4}\) with high probability. They keep \(m\ge1/4\), hence \(\|H\|^2\ge(1+16\varepsilon)^{-1}\), on fixed positive feature intervals and bound the integrated matrix/input action. Do not silently extend this signed-clock argument to arbitrary negative-label feature intervals. [Reachable-tail audit](/home/amir/Codes/PDE/studies/mean_field_peeling/quadratic_compiler/rms_normalized_operator_closure/REACHABLE_TAIL_AUDIT.md:1).

The initialization calculation is nondegenerate. With \(D=27+\varepsilon(3+\varepsilon)^2\), the readout, matrix and input kernel blocks tend respectively to (27/D,36/D,48/D), so \(K_0=111/D>0\). Initial hidden-feature velocity has a positive limit; physical velocity gains \((2\eta y)^2\) for a nonzero limiting label. The finite map is genuinely nonaffine: along \(G=cG_0\), its numerator is quadratic in (c), divided by \(\sqrt{c^4\langle Z_0^4\rangle+\varepsilon}\). These are valid initialization/algebraic facts, not established positive-time convergence.

## 6. A valid continuous-depth result, for a different residual architecture

The complete [original theorem](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/RESNET_MEAN_FIELD_IDE_THEOREM.md:906) and [general-activation theorem](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/CONSTANT_SPECIES_GENERAL_ACTIVATION_IDE.md:263) contain an actual exact-flow width/depth bridge, not merely equations. The general theorem weakens the initialization moment from \(\mathcal P_2\) to \(\mathcal P_1\), with its own full proof.

### Architecture, optimizer and assumptions

For fixed finite sample count \(B\), scalar states and raw parameters \(\theta_{\ell i}\in\mathbb R^p\),

\[
 x_{b,\ell+1}=x_{b,\ell}+{1\over nL}\sum_{i=1}^n
 \Phi(\theta_{\ell i},x_{b,\ell}),\qquad F_b=x_{b,L}.
\]

There is no separate order-one Gaussian trainable readout vector. All raw block parameters train by \(\dot\theta=-\eta nL\nabla_\theta\mathcal E\), where \(\mathcal E=(2B)^{-1}\sum_b(F_b-y_b)^2\). The (nL) multiplier is essential: using \(n\) alone changes the continuous-depth training limit.

A1 requires uniformly bounded \(\Phi(\theta,0)\) and \(\partial_x\Phi\). A2 requires bounded \(\nabla_\theta\Phi\) and jointly Lipschitz \(\partial_x\Phi,\nabla_\theta\Phi\) on each bounded state strip, uniformly over raw \(\theta\). These are assumptions on the **raw parameterization**, not invariant under a change of trainable coordinates. A concrete feature is

\[
 \Phi(\alpha,\omega,\beta;x)=
 \tanh\alpha\,\tanh(\tanh\omega\,x+\tanh\beta).
\]

Bounded effective amplitude/slope/bias are part of this model. The general construction permits suitable \(C^{1,1}\) activations, including arctan, sine and bounded-derivative softplus with bounded effective weights; it does not automatically cover exact ReLU, unbounded effective slopes, or untruncated powers. Initialization is an iid, depth-constant raw law in \(\mathcal P_1(\mathbb R^p)\). [Full assumptions](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/CONSTANT_SPECIES_GENERAL_ACTIVATION_IDE.md:39).

### Limit and proof

The one dynamic species is a depth-indexed measure field \(s\mapsto\rho_t(s)\). Current forward state and backward sensitivity solve

\[
 \partial_s x_b=\int\Phi(\theta,x_b)\,d\rho_t(s),\qquad
 -\partial_s r_b=r_b\int\partial_x\Phi(\theta,x_b)\,d\rho_t(s),
 \quad r_b(1)=1.
\]

Set \(p_b=r_b(F_b-y_b)/B\), \(v=-\eta\sum_b p_b\nabla_\theta\Phi\). Then

\[
 \partial_t\rho+\nabla_\theta\!\cdot(\rho v)=0.
\]

Depth is a spatial coordinate, not a second training-time history. Restart requires the current measure profile alone.

The proof closes because A1–A2 give a deterministic reachable state strip, uniformly bounded adjoints and bounded globally Lipschitz parameter velocities. Coupling characteristics yields depth-averaged \(W_1\) stability \(d_L(\mu_t,\nu_t)\le e^{C_Tt}d_L(\mu_0,\nu_0)\), with constants independent of \(n,L\). The complete integrated-\(W_1\) profile space supports a short-time characteristic contraction and global restart. Shared characteristics with the same initial law give depth regularity without presupposing the discretization result. Coupled forward/adjoint consistency then yields \(O(L^{-1})\); the finite adjoint uses the required downstream index \(r_{\ell+1}\), not \(r_\ell\). [Stability through depth consistency](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/CONSTANT_SPECIES_GENERAL_ACTIVATION_IDE.md:373).

The pathwise final estimate is \(C_T(\delta_{n,L}+L^{-1})\), with \(\delta_{n,L}=L^{-1}\sum_\ell W_1(\rho^{n}_{0,\ell},\rho_0)\). Radial truncation plus compact empirical convergence gives \(\mathbb E\delta_{n,L}=q_n\to0\), independent of \(L\). Consequently **every deterministic joint sequence** \(n,L\to\infty\) converges in probability on compact training horizons, without a rate relation. It covers depth-averaged law error, maximum depth-grid forward/adjoint error, outputs, loss and the \(nL\)-scaled tangent kernel. [Width completion](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/CONSTANT_SPECIES_GENERAL_ACTIVATION_IDE.md:610).

It does not prove maximum-over-layer empirical \(W_1\) convergence for arbitrary (L(n)), almost-sure convergence for arbitrary triangular arrays, standard dense Gaussian ResNet, or long-time optimization. These distinctions are mathematically operative, not cosmetic disclaimers.

### Nonlinearity and nonfrozen transport

The original proof gives \(B=1,x_0=1,y=0,\rho_0=N((2,2,0),I_3)\). The averaged initial residual field is zero at \(x=0\), positive at \(x=1\), and bounded, hence nonaffine. The predictor is positive and the parameter-gradient energy is strictly positive; limiting loss decreases strictly, so the limiting law is not frozen. [Witness proof](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/RESNET_MEAN_FIELD_IDE_THEOREM.md:964). This verifies the manuscript's meaning of “nonlazy”: nonzero limiting transport and order-one dissipation. It deliberately does not prove \(\dot K(0)\ne0\), nor exclusion of all fixed-kernel predictions.

The general proof's finite-moment obstruction is also properly scoped: exact recovery of \(\int\Phi(\theta,x)d\rho\) from fixed linear moments for **all finitely supported laws** forces \(\Phi(\cdot,x)\) into the span of those moments and the constant function. The finite-atomic signed-measure argument proves this; variable-slope analytic nonpolynomial examples have infinite rank. It is not a no-go theorem for every nonlinear finite state, special reachable orbit, approximate closure, or finite-atomic parameterization. [Proposition 12.1](/home/amir/Codes/PDE/studies/mean_field_peeling/residual_continuous_depth_gradient_flow/CONSTANT_SPECIES_GENERAL_ACTIVATION_IDE.md:753).

## 7. Dense ResNet: internal PDE, missing limit bridges, and empirical controls

### Do not merge its scaling with the particle theorem

The canonical dense model has \(H_0=BX\),

\[
 H_{\ell+1}=H_\ell+{\gamma\over L}\sigma(W_\ell H_\ell),
 \qquad f=n^{-1}a^\top H_L,
\]

with iid \(W_{ij}\sim N(0,\sigma_w^2/n)\), order-one Gaussian \(B\) and readout coordinates \(a_i\sim N(0,A^2)\). It trains (W,B,a) with scaled Euclidean rates (L,n,n), respectively, for half the **sum** of sample squared errors. The particle theorem instead averages over \(B\) samples, has a residual mean of independent neurons, and uses (nL). The dense campaign usually has \(d=m=3\); sample count is not hidden depth. Its intended analytic order is width first at fixed depth, then continuous depth. Earlier exploratory \(H_0=\tanh(BX)\) is another model. [Canonical source](/home/amir/Codes/PDE/studies/resnet_pde/operator_pde/core/theory/operator_galerkin_pde.md:16).

The proposed PDE represents row weights through \(P\) immutable Gaussian-label Hermites and a conditional row law. At finite \(P\), retaining the same forward and backward row pairing gives an exact internal gradient identity, PSD tangent matrix and loss dissipation. Those derivations are valid for the projected model. They do not identify its conditional law as the trained dense-network limit. [Internal gradient identity](/home/amir/Codes/PDE/studies/resnet_pde/operator_pde/core/theory/operator_galerkin_pde.md:231).

Two distinct gaps persist:

1. Dense width/depth identification, including trained depth correlations and transpose/Onsager effects.
2. \(P\to\infty\) source-cutoff removal with reachable compactness, consistency and uniqueness/stability. Formal Hermite completeness is not enough. Finite \(P\) still leaves continuum depth and a measure field; numerical (N,M,R) are further discretizations, not \(P\) itself.

For the second gap, the isonormal map (I) is an isometry on an infinite-dimensional source Hilbert space and \(I^*\) is bounded but not compact: independent Gaussian coordinate ξ-mode inputs map to an orthonormal Hermite sequence. Uniform energy/action bounds therefore leave unit tail energy possible above every fixed cutoff. An unbounded Gaussian adjoint boundary also obstructs a simple \(L^2\)-Lipschitz estimate for gate differences. One needs collective reachable compactness plus consistency/uniqueness, or a known infinite flow, vanishing defect and cutoff-uniform forced stability; the dense bridge remains additional. [Complete compactness analysis](/home/amir/Codes/PDE/studies/resnet_pde/pde_convergence/05_tail_and_compactness/COMPACTNESS_REPORT.md:1).

### 10.4 A narrower finite-mesh passage can bypass N, conditionally on the parameter-free theorem

There is a concrete scope reduction for the **actual readout-clipped L2 Euler family**, not for the whole language of Lemma 4.1. It uses the parameter-free transpose theorem [TP III Theorem 2.10](/home/amir/Codes/PDE/studies/mean_field_peeling/three_sample_self_contained/literature/yang_tensor_programs_iii.txt:566), whose permitted operations are fixed coordinate functions and the same Gaussian matrix or its transpose. Here “parameter-free” means no empirical scalar feedback inside that companion program; it does not mean untrained features or a fresh backward matrix.

Fix \(M,S,h\) and a finite number of feature-time steps before taking width to infinity. Equations [7.1–7.2](/home/amir/Codes/PDE/studies/mean_field_peeling/nonlinear_activation_operator_ide/ARCTAN_THEOREM_AND_PROOF.md:628) expose every matrix-update coefficient as

\[
 \langle X^\ell,X^k\rangle_n,\qquad \langle B^\ell,B^k\rangle_n.
\]

On this fixed mesh, \(|A^k|\le M+(\pi/2)S\), and \(X^k,Y^k,B^k\) are uniformly bounded coordinatewise. \(Q^k\) need not be bounded, but it enters the evolving natural coordinate through the **linear** update \(r^{k+1}=r^k+hQ^k\), followed by globally Lipschitz \(\Psi\). This is the specific L2 structure needed below.

Construct a companion program on the **same initialized matrix and marks**, replacing each empirical coefficient, when it is encountered, by the expectation of the corresponding already-defined companion fields. These are recursively defined deterministic constants, not fitted values or future-trajectory information. With the constants frozen, this is a fixed parameter-free program. Conditional on Theorem 2.10, its joint empirical laws and second moments converge, and its necessary fixed-field square tails are tight.

The required comparison follows by finite induction, rather than by estimating regression coefficients of a nearly singular query Gram. For a typical coefficient,

\[
\begin{aligned}
 |\langle U_n,V_n\rangle_n-\mathbb E[\bar U\bar V]|
 \le{}&
 \|U_n-\bar U_n\|_{2,n}\|V_n\|_{2,n}\\
 &+\|\bar U_n\|_{2,n}\|V_n-\bar V_n\|_{2,n}\\
 &+|\langle\bar U_n,\bar V_n\rangle_n-\mathbb E[\bar U\bar V]|.
\end{aligned}
\]

The final term converges by the parameter-free theorem. The first two vanish inductively. Matrix and actual-transpose errors propagate in \(L^2\) by the spectral norm. Coordinate-map errors propagate by global Lipschitz bounds; crucially

\[
 \|Ad(Z)-\bar A d(\bar Z)\|_{2,n}
 \le \|A-\bar A\|_{2,n}
 +(M+\pi S/2)L_d\|Z-\bar Z\|_{2,n}.
\]

Finite sums close the comparison for the fixed number of steps, including \(r,Z,Q,A,X,Y,B\). The same-index empirical coupling gives joint \(W_2\) closeness of the actual and companion fields. No conclusion about higher moments of the *difference* is used. I checked these operations against the actual eliminated Euler equations; this is a bounded dependency reduction, not a new continuous-time proof-search program.

For the raw kernel, one does not need to recover the manuscript's stronger displayed \(2+\varepsilon\) bound for the *actual* feedback program. At a fixed mesh, use the companion's square UI and

\[
 q^2\mathbf1_{\{|q|>R\}}
 \le4(q-\bar q)^2+2\bar q^2\mathbf1_{\{|\bar q|>R/2\}}.
\]

The \(L^2\) comparison transfers square UI to actual \(Q^k_n\). Joint \(W_2\) convergence then passes the continuous quadratic-growth test \(c(r)^2Q^2\). Equivalently, apply the same truncation argument as the manuscript. Choosing one auxiliary mesh and using the already-derived width-uniform clipped Euler estimate transfers these tails to the continuous cutoff flow. This is exactly where **closeness to a UI reference**, rather than a bare \(L^2\) energy bound, matters.

### 10.5 Regularity and endpoint check

For old L2 arctan, the actual maps are global: \(\Theta(u)=u+u^3/3\), \(\iota=\Theta^{-1}\), \(\Psi=\arctan\circ\iota\), \(c=(1+\iota^2)^{-1}\), and \(d(z)=(1+z^2)^{-1}\). Since \(\Theta'\ge1\), \(\iota'=c\le1\), \(\Psi'=c^2\le1\), and \(c'=-2\iota/(1+\iota^2)^3\) is bounded, the needed inverse and gates are globally Lipschitz. The cubic seed has polynomial growth. Finite products have some finite pseudo-Lipschitz degree; no false rule that composition merely adds degrees is required.

Arctan's range endpoints \(\pm\pi/2\) are approached only at infinite input. This program never applies \(\tan\), the inverse of arctan, to the activated field near those endpoints: it retains \(r\) and uses the global \(\iota(r)\). Therefore an unbounded endpoint derivative of \(\tan X\) is not a hidden operation here. Readout clipping is globally Lipschitz, although not \(C^1\) at \(\pm M\); it is an initialization/nonlinearity operation, not differentiation of a clipping optimizer. The parameter-free theorem allows polynomially bounded coordinate maps, so its statement does not impose \(C^2\) or differentiability at these knots.

More generally, a globally admissible \(C^{1,1}\) piecewise map or a Lipschitz extension across endpoints is compatible with this finite-program regularity check. “\(C^{1,1}\) near endpoints” alone is not sufficient for arbitrary operations: global growth, the domain actually queried, and any inverse/derivative inserted into the program still must be checked. The softsign comparison in §9 of the L2 source is not promoted here to an exact-flow theorem.
