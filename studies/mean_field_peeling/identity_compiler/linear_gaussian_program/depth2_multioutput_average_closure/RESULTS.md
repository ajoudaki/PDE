# Multi-output fixed-aggregate closure

Status: exact reduction and inherited positive-time theorem, 20 August 2026.

> **Random-readout extension.**  The same active-direction reduction also
> handles a width-\(n\) frozen Gaussian aggregate whose normalized squared
> norm converges to one.  Applied to the third hidden layer, this yields the
> frozen-readout depth-three theorem in
> [THEOREM_AND_PROOF.md](../depth3_frozen_readout_closure/THEOREM_AND_PROOF.md).

## 1. Exact active-head reduction

Let

\[
f_{a,n}=n^{-3/2}A_a^TWu,\qquad
g_{c,n}=\sum_{a=1}^m c_af_{a,n},
\qquad \gamma=\sum_{a=1}^m c_a^2>0.
\]

With

\[
x_a=A_a/\sqrt n,\qquad y=u/\sqrt n,\qquad B=W/\sqrt n,
\qquad x_c=\sum_a c_ax_a,
\]

feature ascent generated by \(n\nabla g_{c,n}\) is exactly

\[
(x_a)_s=c_aBy,\qquad y_s=B^Tx_c,\qquad B_s=x_cy^T.
\tag{1.1}
\]

Hence

\[
(x_c)_s=\gamma By.
\tag{1.2}
\]

Define

\[
\widehat x=x_c/\sqrt\gamma,\qquad \tau=\sqrt\gamma\,s.
\tag{1.3}
\]

Then

\[
\boxed{
\widehat x_\tau=By,\qquad
y_\tau=B^T\widehat x,\qquad
B_\tau=\widehat xy^T,}
\tag{1.4}
\]

which is exactly the scalar-output characteristic.  Moreover

\[
\boxed{g_{c,n}(s)=\sqrt\gamma\,F_n(\tau),\qquad
K_{c,n}(s)=\gamma K_n(\tau),}
\tag{1.5}
\]

where \(F_n=\widehat x^TBy\) and \(K_n=(F_n)_\tau\) are the scalar-output
feature and kernel.

This is pathwise finite-width algebra, not merely a width-limit symmetry.
At Gaussian initialization, \(\widehat x(0)\) has iid \(N(0,1/n)\) entries
and is independent of \(B(0),y(0)\).  Thus the active system has exactly the
same initialized law as the scalar-output model.

The conserved quantities are correspondingly

\[
\widehat C_n=BB^T-\widehat x\widehat x^T
=BB^T-\gamma^{-1}x_cx_c^T,
\qquad
\|\widehat x\|^2-\|y\|^2.
\tag{1.6}
\]

All output-head directions orthogonal to \(c\) are absent from (1.4).

## 2. The inherited single-source IDE

Use exactly the scalar source

\[
d\nu(\lambda)=\frac34\delta_{-1/2}(d\lambda)
+\frac{(1+\lambda)\sqrt{\lambda(4-\lambda)}}
{\pi(1+2\lambda)}\mathbf1_{(0,4)}(\lambda)d\lambda,
\tag{2.1}
\]

and exactly the scalar initial profiles

\[
(\alpha,\beta)=
\begin{cases}
(1,0),&\lambda=-\tfrac12,\\[1mm]
\left([2(1+\lambda)]^{-1/2},
\sqrt{\dfrac{1+2\lambda}{2(1+\lambda)}}\right),
&0<\lambda<4.
\end{cases}
\tag{2.2}
\]

Set

\[
r=\int|\psi|^2d\nu,\qquad
K=\int\bigl(|\pi|^2+(\lambda+2r)|\psi|^2\bigr)d\nu.
\tag{2.3}
\]

For the scalar aggregate loss

\[
L=(y_\star-g_c)^2,\qquad e=y_\star-g_c,
\]

the autonomous physical-time system is

\[
\boxed{
\begin{aligned}
\partial_t\psi&=2\eta\sqrt\gamma\,e\,\pi,\\
\partial_t\pi&=2\eta\sqrt\gamma\,e\,(\lambda+2r)\psi,\\
\dot e&=-2\eta\gamma\,e\,K,
\end{aligned}}
\tag{2.4}
\]

with

\[
\psi(\lambda,0)=\alpha(\lambda),\qquad
\pi(\lambda,0)=i\beta(\lambda),\qquad e(0)=y_\star.
\tag{2.5}
\]

The readouts are

\[
\boxed{
g_c(t)=y_\star-e(t)
=\sqrt\gamma\,\operatorname{Re}\int\overline\psi\pi\,d\nu,
\qquad L(t)=e(t)^2,}
\tag{2.6}
\]

and

\[
\dot L=-4\eta\gamma K L.
\tag{2.7}
\]

The preservation of (2.6) follows internally because

\[
\frac d{dt}\left[
\sqrt\gamma\,\operatorname{Re}\int\overline\psi\pi\,d\nu
\right]=2\eta\gamma eK=-\dot e.
\]

The previous well-posedness, compact-time identification, and global
physical-time proof apply after the constant transformations (1.3) and
(1.5).  In particular, for every fixed \(m,c\) and finite \(T\),

\[
\sup_{0\le t\le T}|g_{c,n}(t)-g_c(t)|
\xrightarrow{\mathbb P}0,
\]

the limiting physical solution is global, and \(L(t)\to0\).

## 3. Arithmetic mean versus unit-variance aggregate

For the arithmetic average

\[
c_a=\frac1m,\qquad \gamma=\frac1m,
\]

so

\[
g_{\mathrm{av}}=\frac1{\sqrt m}F,\qquad
K_{\mathrm{av}}=\frac1mK,
\tag{3.1}
\]

and (2.4) becomes

\[
\partial_t\psi=\frac{2\eta}{\sqrt m}e\pi,\qquad
\partial_t\pi=\frac{2\eta}{\sqrt m}e(\lambda+2r)\psi,\qquad
\dot e=-\frac{2\eta}{m}eK.
\tag{3.2}
\]

Thus the same closure survives exactly.  Its initial aggregate kernel is
\(3/m\), so at fixed target and learning rate the initial output motion is
suppressed by \(1/m\).  This is not claimed to be a uniform all-time
time-rescaling, because the canonical target becomes \(\sqrt m\,y_\star\).

If instead

\[
c_a=\frac1{\sqrt m},
\]

then \(\gamma=1\), the aggregate has unit initialization scale, and the IDE
is literally identical to the scalar-output IDE with no time or amplitude
factor.

## 4. Individual-output limit

Define the orthogonal head remainder

\[
z_a=x_a-\frac{c_a}{\gamma}x_c.
\tag{4.1}
\]

Equation (1.1) gives \((z_a)_s=0\) exactly, and

\[
f_{a,n}=\frac{c_a}{\gamma}g_{c,n}+z_a^TBy.
\tag{4.2}
\]

Joint Gaussian orthogonal decomposition makes \(z_a(0)\) independent of the
active initial state \((\widehat x(0),B(0),y(0))\).  Conditional on the
active trajectory,

\[
\operatorname{Var}[z_a^TBy]
=\frac{1-c_a^2/\gamma}{n}\|By\|^2.
\tag{4.3}
\]

Consequently, for fixed \(m\), uniformly on compact physical-time intervals,

\[
\boxed{f_a(t)\longrightarrow\frac{c_a}{\gamma}g_c(t).}
\tag{4.4}
\]

For the arithmetic average, \(c_a/\gamma=1\): every output coordinate
converges to the same scalar curve \(g_{\mathrm{av}}\), although finite-width
coordinate differences are \(O_{\mathbb P}(n^{-1/2})\) at each fixed time.

## 5. Vector-MSE boundary

This theorem concerns a fixed aggregate direction.  Generic vector MSE,

\[
\mathcal L_{\mathrm{vec}}
=\frac1m\sum_a(y_a-f_a)^2,
\]

generates the time-dependent direction

\[
\frac1m\sum_a(y_a-f_a)\nabla f_a,
\]

so the one-active-head proof does not apply off a symmetric orbit.

For equal labels, if a deterministic width-limit solution is proved to
remain on \(f_1=\cdots=f_m\), then vector MSE reduces to the arithmetic-mean
system above.  Establishing that invariant-orbit identification from generic
iid finite-width initialization is a separate next theorem, not a consequence
silently included here.
