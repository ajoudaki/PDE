# Quadratic operator-IDE closure campaign

This directory contains the audited attempt to extend the linear
single-sample operator closure to a two-hidden-layer raw-square network.

- PROTOCOL.md freezes the model and the success contract.
- THEOREM_AND_AUDIT.md gives the exact formal pointed-traffic IDE, its readouts,
  the proved compression obstructions, and the unresolved positive-time
  boundary.
- EVIDENCE_LEDGER.md separates proved, conditional, open, superseded, and
  retracted claims.
- FINITE_WIDTH_PROTOCOL.md and FINITE_WIDTH_RESULTS.md contain the
  preregistered boundary-layer diagnostic.
- test_finite_identities.py checks \(f'=K\), both balance families, and the
  hidden rank-one restartability witness.

The central conclusion is deliberately two-level.  The finite equations and
the one-time pointed-traffic **formal full-state lift** are exact at fixed
algebraic order.  They are not yet an admissible positive-time closure: raw
well-posedness, continuous \(f,K\) readouts, uniqueness, and compact-time
width identification remain open.  The cylinder Liouville identity formally
packaging the full hierarchy as one probability mass is exact, but it merely
packages the same all-grade tightness and uniqueness obligations.

The sharpest audited boundaries are:

- a non-iid one-cell sequence makes the output discontinuous in the natural
  \(L^2\oplus L^2\oplus\mathfrak S_1\) parameter topology;
- finite normalized additive-gauge closures fail on a diagonal one-cell
  concentration sequence;
- marginal Orlicz bounds and matrix operator norm alone miss adaptive
  row/column alignment;
- for the canonical iid-Gaussian sequence, an \(o(1)\) fitting layer follows
  from the single dynamic leave-one-row estimate (LOO), but that estimate is
  still open.

Thus the campaign reaches the protocol's rigorous-obstruction outcome, not a
completed canonical quadratic closure or a universal nonexistence theorem.
