# Independent report-only audit protocol

Each reviewer is a newly spawned agent with fork_turns=none. Its only reading input is one immutable complete REPORT.md, containing the theorem, quantitative proof, affine and motion appendices, three-input geometry and explicitly open global question, and full specialized foundational manuscript. No conversation, other project files, preparatory notes, skills, previous reviews, web sources or agent communications are allowed. The reviewer writes only its own report, records the input hash, reading coverage and isolation compliance, and checks every proof obligation. Assigned emphases diversify scrutiny; they do not limit full-document reading. The criterion is mathematical correctness and completeness of the claims actually made, with particular attention to advanced invocations, scope changes and limit orders. A PASS requires no remaining substantive objections or required repairs. Substantive objections must be repaired before an entirely fresh isolated round. No reviewer receives a desired verdict or previous outcomes.
